Go project is called module.
Every module has a go.mod file in its root directory

go.mod (dependency manager) contains:
  1. Name of the module
  2. Minimum supported version of Go for the module
  3. Any other modules that my module depends on

go build:
  1. cria executável

go build -o nome:
  1. cria executável com nome que preferir

go fmt (./...):
  1. arruma o espaçamento de todos arquivos do diretório atual
  2. usar antes de comitar e principalmente antes de buildar
  3. não arruma {} em linha errada
  4. coloca ;(semicolon) ao final das linhas auto

go vet (./...):
  1. detecta se cada placeholder (&s) tem valor correspondente

Makefile:
  1. Automatiza tarefas repetidas (compilar, testar, limpar, etc)
  2. O comando "make" executa o arquivo
